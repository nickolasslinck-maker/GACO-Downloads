- 69 testes automatizados aprovados.

### Distribuição segura

O instalador do GACO ainda não possui assinatura digital própria (o driver de terceiros possui). A instalação do driver solicita consentimento e pode exigir autorização de administrador. O GACO funciona sem o driver; nesse caso, somente a função de controle Xbox virtual fica indisponível.

A conectividade WebRTC/TURN entre redes diferentes requer validação independente do instalador.

Não inserir no repositório credenciais TURN, arquivos de sessões, bancos de dados de usuários nem arquivos locais de teste.
